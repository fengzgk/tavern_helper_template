# 变量更新

在每次回复的**末尾**输出本回合发生的变量变化。没有变化时, 不输出这一块。

    <更新>
    var 好感度 += 10
    var 状态 = "开心"
    </更新>

每行一条语句, 以 `var` 开头, 语句块放在回复最后, 以纯文本形式书写。

## 语句

    var <路径> <赋值符> <表达式>

| 赋值符 | 含义 | 例子 |
|--------|------|------|
| `=` | 覆写为右侧的值 | `var 状态 = "开心"` |
| `+=` | 在当前值上加上右侧 | `var 好感度 += 10` |
| `-=` | 在当前值上减去右侧 | `var 体力 -= 5` |
| `*=` | 在当前值上乘上右侧 | `var 攻击力 *= 1.5` |
| `/=` | 在当前值上除以右侧 | `var 体力 /= 2` |

路径用点号表示层级, 支持中文。

    var 角色.属性.力量 = 10
    var 地点.当前区域 = "钟楼"

数组元素用方括号写下标(从 0 开始), 读取时同样:

    var 物品栏[0] = "药水"
    var 队伍[0].等级 = 5
    var 第一件 = 物品栏[0]

`= None` 表示删除该变量:

    var 角色.临时状态 = None

## 表达式

表达式里的数字、`"字符串"`、`[列表]`、`{字典}`、`+ - * / % // **`、`and` `or` `not`、
`True` `False` `None`、比较(包括 `60 <= 分数 <= 100` 这样的链式写法)、括号以及它们的优先级,
都按你熟悉的 Python 写法书写。

`len` `min` `max` `abs` `str` `int` `float` `bool` 也是同一套。

变量可能是形如 `"50"` 的字符串, 参与运算时会按数字处理, 写回时以计算结果的实际类型为准。

引用其他变量时直接写路径。

    var 是否通过 = 60 <= 分数 <= 100
    var 伤害 = (攻击 + 武器) * 暴击倍率
    var 等级 = 经验 // 100 + 1

## 函数

列表与字符串的增删改写成本文件里的函数, 直接作用在路径上; 函数一律写成 `名字(参数)` 的形式,
数学函数不带 `math.` 前缀, 也不写成 `列表.append(x)` 这样的方法写法。

| 类别 | 函数 |
|------|------|
| 文字 | `insert(i, x)` `cut(i, n)` `replace(old, new)` |
| 列表 | `push(x)` `pop()` `remove(值)` `move(from, to)` |
| 查询 | `len(s)` `sum(arr)` |
| 常用计算 | `min` `max` `clamp(x, lo, hi)` `abs` `floor` `ceil` `round` `if(cond, a, b)` `concat(...)` |
| 类型转换 | `str(x)` `int(x)` `float(x)` `bool(x)` |
| 数学 | `pow` `sqrt` `cbrt` `exp` `log` `log10` `log2` `sin` `cos` `tan` `asin` `acos` `atan` `atan2` `sinh` `cosh` `tanh` `deg` `rad` `sign` `mod` `hypot` `fact` |
| 常量 | `pi` `e` `tau` |

    var 物品栏 = push("药水")
    var 物品栏 = remove("旧剑")
    var 描述 = replace("古旧", "崭新")
    var 状态 = if(体力 > 0, "正常", "疲惫")
    var 全名 = concat(姓, 名)
    var 面积 = pi * r ** 2

条件选择写成 `if(cond, a, b)` 函数; 可识别的函数名就是上面这些, 它们和路径、下标、运算符可以任意组合嵌套。

其中几处的取值含义:

- `push(x)` 在列表末尾追加, 作用等同 `append`
- `pop()` 返回删除末尾之后的整个列表
- `round` 是四舍五入

## 类型

严格按变量本身的类型书写:

| 类型 | 写法 | 例子 |
|------|------|------|
| 数字 | 直接写数字 | `var 好感度 = 50` |
| 字符串 | 用双引号括起来 | `var 状态 = "疲惫"` |
| 布尔 | `True` 或 `False` | `var 是否友好 = True` |
| 列表 | 用方括号 | `var 物品栏 = ["药水"]` |
| 字典 / 对象 | 逐个字段书写 | `var 属性.力量 = 10` |

列表变量的值始终是列表, 只有一个元素也写成 `["药水"]`; 增删改配合 `push` / `remove`, 整体覆写时给出完整列表。

## 计算方式

优先用表达式、函数和赋值符完成计算, 把求值交给脚本:

    var 好感度 += 10
    var 等级 = 经验 // 100 + 1
    var 总金币 = sum(金币列表)
    var 物品栏 = push("药水")
    var 是否通过 = 60 <= 分数 <= 100
    var 状态 = if(体力 > 0, "正常", "疲惫")

累加、取整、汇总、判断、条件选择和数组增删都写成对应的指令, 变量的取值由指令精确算出。

## 完整示例

    <更新>
    var 好感度 += 10
    var 体力 -= 5
    var 状态 = if(体力 > 0, "正常", "疲惫")
    var 物品栏 = push("药水")
    var 金币列表 = push(30)
    var 总金币 = sum(金币列表)
    var 伤害 = (攻击 + 武器) * 暴击倍率
    var 是否通过 = 60 <= 分数 <= 100
    var 距离 = clamp(距离, 0, 100)
    var 角色.称号 = "勇者"
    var 角色.临时状态 = None
    </更新>

## 书写要求

- 一条语句在一行内写完, 语句层赋值只用 `=` `+=` `-=` `*=` `/=`
- 路径用点号连接
- 列表下标与插入位置在有效范围内
- 只输出本回合发生变化的变量
