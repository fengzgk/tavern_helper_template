# 变量更新

在每次回复的**末尾**输出本回合发生的变量变化。没有变化时, 不输出这一块。

    <更新>
    var 好感度 += 10
    var 状态 = "开心"
    </更新>

每行一条语句, 以 `var` 开头, 语句块放在回复最后, 以纯文本形式书写。

## 语句

    var <路径> <赋值符> <表达式>

| 赋值符 | 含义 | 例子 |
|--------|------|------|
| `=` | 覆写为右侧的值 | `var 状态 = "开心"` |
| `+=` | 在当前值上加上右侧 | `var 好感度 += 10` |
| `-=` | 在当前值上减去右侧 | `var 体力 -= 5` |
| `*=` | 在当前值上乘上右侧 | `var 攻击力 *= 1.5` |
| `/=` | 在当前值上除以右侧 | `var 体力 /= 2` |

路径用点号表示层级, 支持中文。

    var 角色.属性.力量 = 10
    var 地点.当前区域 = "钟楼"

数组元素用方括号写下标(从 0 开始), 读取时同样:

    var 物品栏[0] = "药水"
    var 队伍[0].等级 = 5
    var 第一件 = 物品栏[0]

`= null` 表示删除该变量:

    var 角色.临时状态 = null

## 表达式

表达式里的数字、`"字符串"`、`true` / `false`、`[数组]`、`{对象}`、`+ - * / %`、比较、`== !=`、
`&& || !`、括号以及它们的优先级, 都按你熟悉的 JavaScript 写法书写。

`^` 表示幂运算, 优先级高于乘除与一元负号: `2 ^ 3` 是 8, `-2 ^ 2` 是 -4, `2 ^ 3 ^ 2` 是 `2 ^ (3 ^ 2)`。

变量可能是形如 `"50"` 的字符串, 参与运算时会按数字处理, 写回时以计算结果的实际类型为准。

引用其他变量时直接写路径。

    var 是否通过 = (分数 >= 60) && (分数 <= 100)
    var 伤害 = (攻击 + 武器) * 暴击倍率
    var 等级 = floor(经验 / 100) + 1

## 函数

函数一律写成 `名字(参数)` 的形式, 不带 `Math.` 之类的命名空间前缀,
也不写成 `列表.push(x)` 这样的方法调用; 增删改类的函数都返回整个新值, 用 `=` 写回路径。

| 类别 | 函数 |
|------|------|
| 文字与数组的增删改(直接作用于路径, 配 `=`) | `insert(i, x)` `cut(i, n)` `remove(值)` `replace(old, new)` `push(x)` `pop()` `move(from, to)` |
| 查询 | `len(s)` `sum(arr)` |
| 常用计算 | `min` `max` `clamp(x, lo, hi)` `abs` `floor` `ceil` `round` `if(cond, a, b)` `concat(...)` |
| 数学 | `pow` `sqrt` `cbrt` `exp` `log` `log10` `log2` `sin` `cos` `tan` `asin` `acos` `atan` `atan2` `sinh` `cosh` `tanh` `deg` `rad` `sign` `mod` `hypot` `fact` |
| 常量 | `pi` `e` `tau` |

    var 物品栏 = push("药水")
    var 物品栏 = remove("旧剑")
    var 状态 = if(体力 > 0, "正常", "疲惫")
    var 面积 = pi * r ^ 2

可识别的函数名就是上面这些, 它们和路径、下标、运算符可以任意组合嵌套。

其中几处的取值含义:

- `pop()` 返回删除末尾之后的整个数组
- `replace` 把出现的 old 全部替换

## 类型

严格按变量本身的类型书写:

| 类型 | 写法 | 例子 |
|------|------|------|
| 数字 | 直接写数字 | `var 好感度 = 50` |
| 字符串 | 用双引号括起来 | `var 状态 = "疲惫"` |
| 布尔 | `true` 或 `false` | `var 是否友好 = true` |
| 数组 | 用方括号 | `var 物品栏 = ["药水"]` |
| 键值表 / 对象 | 逐个字段书写 | `var 属性.力量 = 10` |

数组变量的值始终是数组, 只有一个元素也写成 `["药水"]`; 增删改配合 `push` / `remove`, 整体覆写时给出完整数组。

## 计算方式

优先用表达式、函数和赋值符完成计算, 把求值交给脚本:

    var 好感度 += 10
    var 等级 = floor(经验 / 100) + 1
    var 总金币 = sum(金币列表)
    var 物品栏 = push("药水")
    var 是否通过 = 60 <= 分数 <= 100
    var 状态 = if(体力 > 0, "正常", "疲惫")

累加、取整、汇总、判断、条件选择和数组增删都写成对应的指令, 变量的取值由指令精确算出。

## 完整示例

    <更新>
    var 好感度 += 10
    var 体力 -= 5
    var 状态 = if(体力 > 0, "正常", "疲惫")
    var 物品栏 = push("药水")

    var 总金币 = sum(金币列表)
    var 伤害 = (攻击 + 武器) * 暴击倍率
    var 是否通过 = (分数 >= 60) && (分数 <= 100)
    var 距离 = clamp(距离, 0, 100)
    var 角色.称号 = "勇者"
    var 角色.临时状态 = null
    </更新>

## 书写要求

- 一条语句在一行内写完, 语句层赋值只用 `=` `+=` `-=` `*=` `/=`
- 路径用点号连接
- 数组下标与插入位置在有效范围内
- 只输出本回合发生变化的变量
