# 变量更新语法

## 输出格式

    <更新>
    var <路径> <赋值符> <表达式>
    let <短名> = <路径>
    define <名字>(<形参>) = <表达式>
    </更新>

- 每行一条语句, 独占一行
- 写变量用 `var`; 给长路径起短名用 `let`; 定义本块内用的函数用 `define`
- 只在确实发生变化的回合输出这一块
- `<更新>` 只是便于阅读的分隔标记, 脚本只识别其中以 `var` `let` `define` 开头的行
- 某一条语句写成脚本无法识别的形式时, 只有那一条不生效, 同一块里其余语句照常写入


## 语句格式

    var <路径> <赋值符> <表达式>
    let <短名> = <路径>
    define <名字>(<形参>) = <表达式>

## 注释

`#` 之后的内容是注释, 可以整行写, 也可以写在语句末尾。

    # 这一行是注释
    var 好感度 += 10  # 主角对这件事的态度

## 赋值符

| 符号 | 含义 | 例子 |
|------|------|------|
| `=`  | 覆写为右侧的值 | `var 状态 = "开心"` |
| `+=` | 在当前值上加上右侧 | `var 好感度 += 10` |
| `-=` | 在当前值上减去右侧 | `var 体力 -= 5` |
| `*=` | 在当前值上乘上右侧 | `var 攻击力 *= 1.5` |
| `/=` | 在当前值上除以右侧 | `var 体力 /= 2` |

- `+=` 的左侧是数组时, 按「追加元素」理解(与 `push` 相同), 不会拼成字符串: `var 物品栏 += "药水"`
- 路径还不存在时, `+=` `-=` 从 0 开始算, `*=` `/=` 从 1 开始算


## 路径

- 用点号表示层级
- 数组元素用方括号写下标, 从 0 开始
- 两者可以混用

    var 角色.属性.力量 = 10
    var 地点.当前区域 = "钟楼"
    var 物品栏[0] = "药水"
    var 队伍[0].等级 = 5

读取时同样写路径:

    var 第一件 = 物品栏[0]
    var 队长等级 = 队伍[0].等级


## 删除变量

    var 角色.临时状态 = null

## 变量类型: 严格按变量本身的类型书写

| 变量类型 | 写法 | 例子 |
|----------|------|------|
| 数字 | 直接写数字 | `var 好感度 = 50` |
| 字符串 | 用双引号括起来 | `var 状态 = "疲惫"` |
| 布尔 | `true` 或 `false` | `var 是否友好 = true` |
| 数组 | 用方括号, 元素按类型书写 | `var 物品栏 = ["药水", "面包"]` |
| 数组追加 | 用 `push(...)` | `var 物品栏 = push("药水")` |
| 数组删除 | 用 `remove(...)` | `var 物品栏 = remove("旧剑")` |
| 键值表 / 对象 | 逐个字段书写 | `var 属性.力量 = 10` |

数组变量的值必须是数组, **只有一个元素也要写成数组**:

    var 物品栏 = ["药水"]

数字变量的值必须是数字:

    var 好感度 = 50

## 计算方式

优先用表达式、函数和赋值符完成计算, 把求值交给脚本:

    var 好感度 += 10
    var 等级 = floor(经验 / 100) + 1
    var 总金币 = sum(金币列表)
    var 物品栏 = push("药水")
    var 是否通过 = 60 <= 分数 <= 100
    var 状态 = if(体力 > 0, "正常", "疲惫")

累加、取整、汇总、判断、条件选择和数组增删都写成对应的指令, 变量的取值由指令精确算出。

`+` 的两侧都能当作数字时做数字加法, 否则做字符串拼接; 其余运算符和比较都按数字计算。要拼接字符串并确保拿到文本时用 `concat` 或 `str`。

## 引用其他变量

直接写路径即可。

    var 是否通过 = 分数 >= 60
    var 伤害 = 攻击 + 武器
    var 状态 = if(体力 > 0, "正常", "疲惫")

## let: 给长路径起短名

路径很长时, 用 `let <短名> = <路径>` 起个短名, 之后在这一块语句里用短名代替它, 读和写都指向同一个位置。

    let 面板 = 角色
    var 面板.称号 = "勇者"
    var 面板.临时状态 = null

    let 经验条 = 角色.属性.经验
    var 经验条 += 50
    var 升级还需 = 100 - 经验条

- `let` 右侧必须是一条路径
- 短名只在这一块语句里有效, 不产生新变量, 也不出现在变量结果里
- 短名只在整段路径相等时替换: `let 题 = 角色` 之后写 `题目` 仍是原来那个 `题目`
- 短名可以再起短名: `let a = 角色` 之后 `let b = a.属性` 指向 `角色.属性`

## define: 定义这一块里用的函数

`define <名字>(<形参>) = <表达式>` 定义一个函数, 之后用 `名字(实参)` 调用它。`def` 是同样的写法。

    define 平方(x) = x ^ 2
    var 距离 = sqrt(平方(dx) + 平方(dy))

    define 衰减(初始, 次数) = 初始 * 0.5 ^ 次数
    var 体力 = 衰减(体力, 3)

- 函数体里可以用形参、路径、其他函数和已经写过的 `define`
- 函数可以调用自己
- 函数只在这一块语句里有效, 不产生新变量
- 同名时 `define` 的函数优先于内置函数

## 运算符

从高到低:

| 优先级 | 运算符 | 说明 |
|--------|--------|------|
| 1 | `()` | 括号 |
| 2 | `^` | 幂, 右结合 |
| 3 | `!`、一元 `-` | 逻辑非、负号 |
| 4 | `*` `/` `%` | 乘、除、取余 |
| 5 | `+` `-` | 加、减 |
| 6 | `<` `>` `<=` `>=` | 比较 |
| 7 | `==` `!=` | 判断相等 |
| 8 | `&&` | 逻辑与 |
| 9 | `\|\|` | 逻辑或 |

- 幂用 `^`, 取余用 `%`
- `^` 右结合: `2 ^ 3 ^ 2` 等于 `2 ^ (3 ^ 2)`
- `-2 ^ 2` 等于 `-(2 ^ 2)`, 结果是 `-4`
- 拿不准优先级时用括号

## 函数

### 文字与数组的增删改

首参数省略, 直接把路径当作被操作的对象。

| 函数 | 含义 |
|------|------|
| `insert(i, x)` | 在位置 i 插入: 字符串插入子串, 数组插入元素 |
| `cut(i, n)` | 从位置 i 起删除 n 个字符 |
| `remove(值)` | 数组删除该元素; 字符串删除该子串 |
| `replace(old, new)` | 把 old 全部替换为 new |
| `push(x)` | 数组末尾追加 |
| `pop()` | 数组删除末尾元素 |
| `move(from, to)` | 把第 from 个元素移到第 to 位 |

    var 地点名 = insert(2, "的")
    var 描述 = replace("古旧", "崭新")
    var 物品栏 = push("药水")
    var 物品栏 = pop()
    var 物品栏 = remove("旧剑")

这些函数返回完整的新值, 必须配 `=`:

    var 物品栏 = push("药水")

- `push(x)` 的 x 是数组时按元素追加: `push(["药水", "面包"])` 一次追加两个元素, 要把数组本身当作一个元素追加时写成 `push([["药水", "面包"]])`
- `remove(值)` 删除首个匹配的元素或子串, 该值必须确实存在

### 查询

| 函数 | 含义 |
|------|------|
| `len(s)` | 字符串 / 数组 / 键值表的长度 |
| `sum(arr)` | 数组求和 |
| `sum(变量, 起始, 终止, 表达式)` | 把变量从 起始 取到 终止(含两端) 代入表达式后求和 |

    var 名称长度 = len(地点名)
    var 物品数 = len(物品栏)
    var 总金币 = sum(金币列表)

区间求和用来写累加式, 循环变量用单个标识符, 起止都取整数:

    var 平方和 = sum(i, 1, 10, i ^ 2)
    var 巴塞尔 = sum(i, 1, 1000, 1 / i ^ 2)
    var 血量总计 = sum(i, 0, len(队伍) - 1, 队伍[i].等级)

### 常用计算

| 函数 | 含义 |
|------|------|
| `min(...)` `max(...)` | 取最小 / 最大 |
| `clamp(x, lo, hi)` | 限制在 lo 到 hi 之间 |
| `abs(x)` | 绝对值 |
| `floor(x)` `ceil(x)` `round(x)` | 向下取整 / 向上取整 / 四舍五入 |
| `if(cond, a, b)` | cond 为真取 a, 否则取 b |
| `concat(a, b, ...)` | 字符串拼接 |
| `str(x)` `int(x)` `float(x)` `bool(x)` | 转成字符串 / 整数 / 小数 / 布尔值 |
| `isclose(a, b, tol)` | 两数之差不超过 tol 时取 `true`, tol 省略时用 `1e-12`; 别名 `approx` |

    var 状态 = if(体力 > 0, "正常", "疲惫")
    var 距离 = clamp(距离, 0, 100)
    var 等级 = floor(经验 / 100) + 1
    var 全名 = concat(姓, 名)
    var 等级文本 = str(等级)
    var 是否一致 = isclose(总金币, 金币列表[0])
    var 数值吻合 = isclose(半径, cbrt(体积 * 3 / (4 * pi)), 1e-9)

浮点数经过不同算式可能差最后几位, 判断两个数是否一致时用 `isclose`, 需要精确相等时才写 `==`。

`bool(x)` 把 `"true"` `"1"` 当作真, 把 `"false"` `"0"` 和空串当作假; `round` 是四舍五入(半数远离零)。

### 数学

| 函数 | 含义 |
|------|------|
| `pow(a, b)` | a 的 b 次方 |
| `sqrt(x)` `cbrt(x)` | 平方根 / 立方根 |
| `exp(x)` `log(x)` `log10(x)` `log2(x)` | 指数 / 自然对数 / 常用对数 / 以 2 为底 |
| `sin(x)` `cos(x)` `tan(x)` | 正弦 / 余弦 / 正切, 参数是弧度 |
| `asin(x)` `acos(x)` `atan(x)` `atan2(y, x)` | 反三角函数 |
| `sinh(x)` `cosh(x)` `tanh(x)` | 双曲函数 |
| `deg(x)` `rad(x)` | 弧度转角度 / 角度转弧度 |
| `sign(x)` | 符号, 返回 -1 / 0 / 1 |
| `mod(a, b)` | 取余 |
| `hypot(a, b)` | √(a² + b²) |
| `fact(n)` | 阶乘 |

常量 `pi` `e` `tau` 直接写:

    var 面积 = pi * r ^ 2
    var 斜边 = hypot(a, b)
    var 角度 = deg(atan2(dy, dx))
    var 半径 = cbrt(体积 * 3 / (4 * pi))
    var 振幅 = sin(rad(相位)) * 最大振幅

## 书写要求

- 语句只使用本文件列出的语法: `var` 语句、`let` 短名、`define` 函数、路径、赋值符、表达式、函数调用
- 一条语句在一行内写完
- 语句层赋值只用 `=` `+=` `-=` `*=` `/=`
- 路径用点号连接
- 数组下标与插入位置在有效范围内
- 只输出本回合发生变化的变量
