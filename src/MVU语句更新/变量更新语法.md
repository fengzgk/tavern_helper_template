# 变量更新语法

## 输出格式

    <更新>
    var <路径> <赋值符> <表达式>
    </更新>

- 每行一条语句, 以 `var` 开头, 独占一行


## 语句格式

    var <路径> <赋值符> <表达式>

## 赋值符

| 符号 | 含义 | 例子 |
|------|------|------|
| `=`  | 覆写为右侧的值 | `var 状态 = "开心"` |
| `+=` | 在当前值上加上右侧 | `var 好感度 += 10` |
| `-=` | 在当前值上减去右侧 | `var 体力 -= 5` |
| `*=` | 在当前值上乘上右侧 | `var 攻击力 *= 1.5` |
| `/=` | 在当前值上除以右侧 | `var 体力 /= 2` |


## 路径

- 用点号表示层级
- 数组元素用方括号写下标, 从 0 开始
- 两者可以混用

    var 角色.属性.力量 = 10
    var 地点.当前区域 = "钟楼"
    var 物品栏[0] = "药水"
    var 队伍[0].等级 = 5

读取时同样写路径:

    var 第一件 = 物品栏[0]
    var 队长等级 = 队伍[0].等级


## 删除变量

    var 角色.临时状态 = null

## 变量类型: 严格按变量本身的类型书写

| 变量类型 | 写法 | 例子 |
|----------|------|------|
| 数字 | 直接写数字 | `var 好感度 = 50` |
| 字符串 | 用双引号括起来 | `var 状态 = "疲惫"` |
| 布尔 | `true` 或 `false` | `var 是否友好 = true` |
| 数组 | 用方括号, 元素按类型书写 | `var 物品栏 = ["药水", "面包"]` |
| 数组追加 | 用 `push(...)` | `var 物品栏 = push("药水")` |
| 数组删除 | 用 `remove(...)` | `var 物品栏 = remove("旧剑")` |
| 键值表 / 对象 | 逐个字段书写 | `var 属性.力量 = 10` |

数组变量的值必须是数组, **只有一个元素也要写成数组**:

    var 物品栏 = ["药水"]

数字变量的值必须是数字:

    var 好感度 = 50

## 计算方式

优先用表达式、函数和赋值符完成计算, 把求值交给脚本:

    var 好感度 += 10
    var 等级 = floor(经验 / 100) + 1
    var 总金币 = sum(金币列表)
    var 物品栏 = push("药水")
    var 是否通过 = 60 <= 分数 <= 100
    var 状态 = if(体力 > 0, "正常", "疲惫")

累加、取整、汇总、判断、条件选择和数组增删都写成对应的指令, 变量的取值由指令精确算出。

## 引用其他变量

直接写路径即可。

    var 是否通过 = 分数 >= 60
    var 伤害 = 攻击 + 武器
    var 状态 = if(体力 > 0, "正常", "疲惫")

## 运算符

从高到低:

| 优先级 | 运算符 | 说明 |
|--------|--------|------|
| 1 | `()` | 括号 |
| 2 | `^` | 幂, 右结合 |
| 3 | `!`、一元 `-` | 逻辑非、负号 |
| 4 | `*` `/` `%` | 乘、除、取余 |
| 5 | `+` `-` | 加、减 |
| 6 | `<` `>` `<=` `>=` | 比较 |
| 7 | `==` `!=` | 判断相等 |
| 8 | `&&` | 逻辑与 |
| 9 | `\|\|` | 逻辑或 |

- 幂用 `^`, 取余用 `%`
- `^` 右结合: `2 ^ 3 ^ 2` 等于 `2 ^ (3 ^ 2)`
- `-2 ^ 2` 等于 `-(2 ^ 2)`, 结果是 `-4`
- 拿不准优先级时用括号

## 函数

### 文字与数组的增删改

首参数省略, 直接把路径当作被操作的对象。

| 函数 | 含义 |
|------|------|
| `insert(i, x)` | 在位置 i 插入: 字符串插入子串, 数组插入元素 |
| `cut(i, n)` | 从位置 i 起删除 n 个字符 |
| `remove(值)` | 数组删除该元素; 字符串删除该子串 |
| `replace(old, new)` | 把 old 全部替换为 new |
| `push(x)` | 数组末尾追加 |
| `pop()` | 数组删除末尾元素 |
| `move(from, to)` | 把第 from 个元素移到第 to 位 |

    var 地点名 = insert(2, "的")
    var 描述 = replace("古旧", "崭新")
    var 物品栏 = push("药水")
    var 物品栏 = pop()
    var 物品栏 = remove("旧剑")

这些函数返回完整的新值, 必须配 `=`:

    var 物品栏 = push("药水")

### 查询

| 函数 | 含义 |
|------|------|
| `len(s)` | 字符串 / 数组 / 键值表的长度 |
| `sum(arr)` | 数组求和 |

    var 名称长度 = len(地点名)
    var 物品数 = len(物品栏)
    var 总金币 = sum(金币列表)

### 常用计算

| 函数 | 含义 |
|------|------|
| `min(...)` `max(...)` | 取最小 / 最大 |
| `clamp(x, lo, hi)` | 限制在 lo 到 hi 之间 |
| `abs(x)` | 绝对值 |
| `floor(x)` `ceil(x)` `round(x)` | 向下取整 / 向上取整 / 四舍五入 |
| `if(cond, a, b)` | cond 为真取 a, 否则取 b |
| `concat(a, b, ...)` | 字符串拼接 |

    var 状态 = if(体力 > 0, "正常", "疲惫")
    var 距离 = clamp(距离, 0, 100)
    var 等级 = floor(经验 / 100) + 1
    var 全名 = concat(姓, 名)

### 数学

| 函数 | 含义 |
|------|------|
| `pow(a, b)` | a 的 b 次方 |
| `sqrt(x)` `cbrt(x)` | 平方根 / 立方根 |
| `exp(x)` `log(x)` `log10(x)` `log2(x)` | 指数 / 自然对数 / 常用对数 / 以 2 为底 |
| `sin(x)` `cos(x)` `tan(x)` | 正弦 / 余弦 / 正切, 参数是弧度 |
| `asin(x)` `acos(x)` `atan(x)` `atan2(y, x)` | 反三角函数 |
| `sinh(x)` `cosh(x)` `tanh(x)` | 双曲函数 |
| `deg(x)` `rad(x)` | 弧度转角度 / 角度转弧度 |
| `sign(x)` | 符号, 返回 -1 / 0 / 1 |
| `mod(a, b)` | 取余 |
| `hypot(a, b)` | √(a² + b²) |
| `fact(n)` | 阶乘 |

常量 `pi` `e` `tau` 直接写:

    var 面积 = pi * r ^ 2
    var 斜边 = hypot(a, b)
    var 角度 = deg(atan2(dy, dx))
    var 半径 = cbrt(体积 * 3 / (4 * pi))
    var 振幅 = sin(rad(相位)) * 最大振幅

## 书写要求

- 语句只使用本文件列出的语法: `var` 语句、路径、赋值符、表达式、函数调用
- 一条语句在一行内写完
- 语句层赋值只用 `=` `+=` `-=` `*=` `/=`
- 路径用点号连接
- 数组下标与插入位置在有效范围内
- 只输出本回合发生变化的变量
